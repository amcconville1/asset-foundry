# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive. Critique work, not people. No harassment,
insults or discrimination, in issues, pull requests, reviews or anywhere else the project
meets.

Report a problem by opening a private security advisory on the repository (see
`SECURITY.md`) or by contacting the maintainer through their GitHub profile. Reports are
kept confidential. The maintainer may remove comments, close threads or block participants
who break these rules.
